# غلاف ترتيل لنظام Android

هذا المجلد يحتوي غلاف Capacitor مؤقتاً يفتح أحدث نسخة منشورة من منصة ترتيل عبر اتصال HTTPS. الغلاف ليس إعادة بناء أصلية لواجهات التطبيق، ولا يعمل دون اتصال بالإنترنت، ولا ينسخ قاعدة البيانات أو أسرار المصادقة إلى الهاتف.

## البناء المحلي

يتطلب البناء المحلي Node.js وJava وAndroid SDK. من داخل هذا المجلد شغّل `pnpm install` ثم `pnpm cap:add`، وبعدها يمكن فتح مشروع Android عبر `pnpm cap:open`. لا تُضع أي قيم سرية في هذا المجلد أو داخل APK.

## البناء عبر GitHub Actions

يوفر سير العمل في `.github/workflows/build-apk.yml` بناء APK تجريبي Debug باستخدام Android SDK على GitHub Actions. الناتج يُحفظ كـ artifact، ويمكن لاحقاً إرفاقه بإصدار GitHub بعد التحقق منه. نسخة Release موقعة تتطلب keystore وإدارة أسرار منفصلة، ولم تُنشأ تلقائياً.

## حدود مهمة

يعتمد الغلاف على الرابط `https://tarteel-qura-8kmxg5hu.manus.space`. إذا تغيّر الرابط أو توقفت الاستضافة الأصلية فلن يعمل الغلاف حتى يتم تحديث الإعداد وإعادة البناء. تسجيل الدخول والبيانات يظلان تابعين لخادم ترتيل المنشور؛ الغلاف لا يمنح صلاحيات إضافية ولا يتجاوز المصادقة.
