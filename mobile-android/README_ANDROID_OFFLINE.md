# ترتيل Android Offline‑First — المرحلة الأولية

هذا المجلد هو بداية تطبيق Android أصلي مستقل باستخدام Expo/React Native، وليس غلاف WebView. لا يستخدم `server.url` ولا يفتح رابط ترتيل المنشور. تبقى نسخة الويب في جذر المستودع مستقلة وغير مستبدلة.

## ما تم تنفيذه في هذه المرحلة

تم إنشاء مشروع Android أصلي مع هوية ترتيل العربية، اتجاه RTL، شاشة رئيسية محلية، مراقبة الاتصال، SQLite محلية، جداول أساسية للبيانات التعليمية، جداول `sync_outbox` و`sync_conflicts` و`sync_metadata`، تخزين جلسة محلية عبر SecureStore، Repository أولي، وSync Engine يدعم حالات النجاح والتعارض وإعادة المحاولة. أضيفت اختبارات Vitest لعقد المزامنة.

## ما لم يُنفذ بعد

هذه ليست نسخة إنتاجية Offline‑First بعد. لم تُربط بعد بمصادقة Manus أو عقد Sync حقيقي على الخادم، ولم تُنقل جميع شاشات المراكز والحلقات والطلاب والجلسات والتقارير والمصحف إلى Android. لا توجد بعد سياسة نهائية لحل التعارضات التعليمية، ولا Release APK/AAB موقّع.

## التشغيل المحلي

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm prebuild
pnpm android
```

يتطلب تشغيل `pnpm android` جهاز Android أو محاكياً وAndroid SDK. عند البناء في بيئة CI يجب توفير JDK وAndroid SDK وقراءة `android/local.properties` من البيئة المحلية فقط؛ لا تُرفع كلمات المرور أو keystore إلى المستودع.

## قواعد الأمان

لا تُحفظ كلمات المرور في SQLite أو SecureStore. تُحفظ جلسة محلية محدودة الصلاحية ولقطة صلاحيات بعد دخول Online، وتبقى العمليات التعليمية غير المتزامنة داخل Outbox حتى يؤكدها الخادم. لا يجوز اعتبار إخفاء زر في الواجهة حماية؛ كل Repository وAdapter يجب أن يطبق نطاق المستخدم.

## معيار الانتقال للمرحلة التالية

لا تنتقل ميزة إلى حالة «مكتملة» إلا بعد اختبار القراءة والكتابة دون شبكة، إغلاق التطبيق أثناء الحفظ، إعادة التشغيل، إعادة المحاولة، تعارض النسخ، منع الوصول بين المراكز، ترقية SQLite، واسترجاع البيانات. كما يجب أن يمر بناء Debug وAAB غير موقّع قبل إعداد Release موقّع بأسرار يضيفها مالك المستودع إلى GitHub Secrets.

## آخر حالة تنفيذ موثقة

تم تضمين أصل Tanzil Uthmani محلياً داخل `assets/quran/tanzil-uthmani.txt` مع إشعار الترخيص في `assets/quran/TANZIL-LICENSE.txt` ومدقق بنيوي يتحقق من 6236 آية و114 سورة. أضيف قارئ محلي وبحث عربي دون `fetch` أو CDN.

تمت إضافة Repository تعليمي محلي لتسجيل الجلسات والحضور والحفظ والمراجعة عبر SQLite وOutbox مع حارس نطاقات وصلاحيات. كما أضيف ملخص لوحة محلي وعدّادات الكيانات.

نتيجة الاختبارات الحالية: **15 اختباراً ناجحاً في 6 ملفات** مع نجاح TypeScript. ما زال ربط Remote Adapter بعقد الخادم، والمصادقة الحقيقية، ومزامنة الخلفية، ونقل جميع شاشات الويب، وتوقيع Release غير مكتمل؛ لذلك لا تُسمّى هذه النسخة إصدار Android Offline نهائياً.
