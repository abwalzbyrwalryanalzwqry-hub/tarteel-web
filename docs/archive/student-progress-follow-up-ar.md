# تقدم الطالب والمتابعة التعليمية

## نطاق التحسين

يعرض ملف الطالب الآن **مسار المتابعة الحالي** إلى جانب سجلات الحفظ والمراجعة الأصلية. لا يحسب هذا القسم أهدافاً مستقبلية أو يتوقع مستوى الطالب؛ بل يستخرج آخر موضع حفظ وآخر موضع مراجعة، وعدد السجلات، وإجمالي الصفحات المدخلة في الفترة التي اختارها المستخدم.

| الدور | البيانات المعروضة في التحسين | البيانات المستبعدة من العرض |
|---|---|---|
| المدير والمعلم | ملخص التقدم، الحضور، مؤشرات المتابعة التفسيرية، وسجل التقييمات | لا يوجد تغيير في سلطات التعديل الأصلية |
| الطالب | ملخص الحفظ والمراجعة والسجل الزمني الشخصي | الحضور، التقييمات، ومؤشرات المعلم |
| ولي الأمر | ملخص الحفظ والمراجعة والحضور والسجل الزمني للابن المرتبط | التقييمات ومؤشرات المعلم |

## مؤشرات المعلم

يظهر للمدير أو المعلم قسم «تنبيهات متابعة المعلم» فقط. يشرح هذا القسم سبب كل تنبيه بدقة: غياب سجل مراجعة عندما يوجد سجل حفظ، أو نسبة حضور دون 80% عند وجود حالات حضور معتمدة، أو وجود سجل مراجعة حديث. لا يمنع التنبيه اعتماد الفترة ولا يغيّر بيانات الطالب تلقائياً.

> تظهر عبارة «لم يُسجّل بعد» عندما لا توجد بيانات فعلية، ولا تستبدل بسورة أو آية أو نسبة تقديرية.

## التشغيل اليومي

ينصح المعلم بفتح الملف بعد اعتماد الفترة لمراجعة آخر نطاق موثق، ثم يفتح سجل الطالب في الفترة التالية لتسجيل النطاق الجديد. تتحدث نتائج الملف تلقائياً عند تغيير نطاق التاريخ، لذا ينبغي اختيار فترة مناسبة قبل مقارنة السجلات أو الاعتماد عليها في متابعة الطالب.
