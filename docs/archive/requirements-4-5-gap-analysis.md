# مطابقة متطلبات الملفين الرابع والخامس مع ترتيل

## قرار الدمج

راجعت المتطلبات الواردة في الملفين مع صفحات الحلقة والجلسة وملف الطالب ومركز القرآن الحالية. سيحافظ التنفيذ على نظام ألوان وترتيل وواجهته RTL وخطي Amiri وTajawal؛ ولن يعاد بناء أي شاشة أو تُنشأ هوية مرجعية موازية. تُنفّذ فقط التحسينات التي تضيف سلوكاً جديداً أو تكمل تدفقاً قائماً.

| المجال المطلوب | حالة ترتيل الحالية | قرار التنفيذ |
|---|---|---|
| الحلقة والمجموعة وتبويبات الطلاب والجلسات والأعضاء | موجودة في لوحة الحلقة، مع الفترات والسجل الشهري | لا إعادة بناء؛ ستتحسن بطاقات الطلاب وإجراءاتها السريعة فقط. |
| الجلسة اليومية والتواريخ الهجرية والميلادية | موجودة في الجلسة وتفاصيلها | إضافة تقويم شهري انتقائي بعلامات الجلسات وتصفية اليوم. |
| الحضور بأربع حالات وإحصاءات | موجود مع عدادات الجلسة | إضافة تحديث متفائل للبطاقات السريعة لضمان الاستجابة الفورية. |
| الحفظ والمراجعة والسور والآيات | موجودان منفصلين، مع حدود خادمية وحدود متحركة | لا تكرار؛ ستُحسّن نافذة التسجيل بتقييم نجوم وربط مصحف يحفظ سياق النموذج. |
| ملف الطالب والسجل | موجود مع فلاتر التاريخ ومؤشرات وسجل إنجاز | إضافة تبويبات تحليلية متسقة، والنسب والمتوسطات غير المعروضة بعد. |
| فتح المرجع القرآني | موجود برابط السورة والآية إلى مركز القرآن | استبدال الانتقال المفقِد لحالة الحوار بفتح مرجع مستقل يحافظ على نموذج الإدخال. |
| ملاحظات مصنفة وتعديل/حذف كل سجل | الملاحظات نصية حالياً والإجراءات جزئية | مؤجل لتوسعة بيانات وسياسات تدقيق منفصلة، تجنباً لإضافة تصنيف أو حذف غير مدروس. |
| تنبيهات ذكية وتقارير | توجد الإشعارات والتقارير والتصدير | لا تكرار في هذه الدفعة؛ تظل التحسينات الذكية امتداداً مستقلاً لاحقاً. |

## نطاق الدفعة

تضيف الدفعة تقويم جلسات ضمن الشاشة القائمة، وملخص حضور سريع بتحديث متفائل، وواجهة تقييم نجوم تحول الاختيار إلى الدرجة الحالية المتوافقة مع قاعدة البيانات، وربطاً عميقاً يحافظ على حالة نافذة التسجيل، وملف طالب منظم بتبويبات تحليلات دون نسخ البيانات أو تغيير مخططها. تُختبر الدوال المشتركة والواجهة السلوكية، ثم يُتحقق من المسارات في جلسة محلية مصادق عليها.

## تحقق بصري أولي

ظهرت لوحة حلقة **نسائم الجنة** بحلقة تحتوي طالبتين فعليتين. تحققت بطاقات الطلاب الجديدة من عرض الاسم والحالة وآخر حفظ ومراجعة وملخص الحضور والغياب والاستئذان والتأخر، مع أزرار الحضور السريعة الأربعة. لعدم وجود جلسة مفتوحة، ظهرت الأزرار بحالة معطلة وإرشاد صريح لفتح جلسة أولاً؛ وهو سلوك يمنع تسجيل حضور خارج جلسة مرتبطة. بقي التحقق التفاعلي للتحديث المتفائل مرتبطاً بفتح جلسة فعلية.

ظهرت شاشة الجلسات بقائمة الجلسات الفعلية وزر التقويم الجديد. فتح الزر تقويماً متوافقاً مع الهوية الحالية، يعرض الشهر الجاري ويجعل اليوم الحالي واضحاً ويشرح أن الأيام المظللة تحتوي جلسات. يتيح التقويم الانتقال بين الشهور واختيار يوم لتصفية القائمة، مع بقاء التاريخ الهجري الظاهر في تفاصيل كل جلسة دون استبدال.

ظهر ملف الطالبة **رقية** بعد التوسعة، مع فلاتر التاريخ وتبويبات الملخص والحفظ والمراجعة والحضور والتقييمات والسجل. تحققت مؤشرات نسبة الحضور والغياب والتأخر ومتوسط التقييم، وبطاقات الحفظ والمراجعة ورابط فتح المصحف. كما فُتح تبويب التقييمات وأظهر حالة فارغة واضحة عندما لا توجد تقييمات، دون أخطاء تخطيطية أو تشغيلية.

في جلسة فعلية للحلقة، فُتحت نافذة تسجيل إنجاز الطالبة رقية. ظهرت تبويبات الحفظ والمراجعة والتقييم، وقائمتا السور التابعتان وحدود آيات الفاتحة من 1 إلى 7، وزر **فتح موضع البداية في المصحف** ضمن النافذة. النافذة تعزل النموذج فوق الجلسة وتحافظ على سياق السورة والآية عند فتح المرجع في علامة مستقلة.

فُتح تبويب التقييم داخل النافذة نفسها، وظهرت خمسة أزرار نجوم قابلة للوصول مع الحقول التفصيلية القائمة. اختيار النجمة الخامسة غيّر الحالة الفورية إلى **ممتاز · 5/5** من دون حفظ أي سجل تجريبي؛ وبذلك تحققت استجابة اختيار النجوم والنص الإرشادي قبل الحفظ.
